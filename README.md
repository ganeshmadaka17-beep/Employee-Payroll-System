## Description
PayDesk manages employee records and calculates salaries automatically. Data is saved in the browser using LocalStorage.

## Features
- Add, edit and delete employees with form validation
- Automatic salary: HRA 20%, DA 10%, PF 12%, tax 5% (gross above ₹30,000)
- Live summary: employee count, total gross, total net, average net
- Search by name or department, and sort by name or net pay
- Printable payslip for every employee

## How to run
1. Open `04_Website/index.html` in any browser.
2. Add employees using the form. No installation needed.

## Technologies
MS Word, MS Excel, MS PowerPoint, HTML, CSS, JavaScript
